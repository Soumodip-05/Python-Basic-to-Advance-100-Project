# 📌 About This Repository

Welcome to my **100 Days of Python Learning & Projects Challenge**.

This repository documents my complete Python learning journey — starting from Python basics and gradually moving toward advanced concepts, data structures, OOP, automation, GUI applications, AI/ML, and real-world software projects.

Alongside theory and fundamentals, I am building **100 Python projects** ranging from beginner-friendly applications to advanced AI-powered systems.

The main objective of this challenge is to:

* Learn Python from basics to advanced level
* Build consistency through daily coding
* Create real-world projects
* Learn software development workflows
* Improve problem-solving abilities
* Build an impressive developer portfolio
